# RSSリーダー 要求仕様

## 概要

Windows上で動作するデスクトップ用RSSリーダー。あらかじめ設定ファイルに登録したRSSフィードを取得し、全フィードの記事を1つの一覧にまとめてGUIに表示する。記事をクリックすると既定のブラウザで記事URLを開き、開いた記事は「既読」として記憶されグレー表示になる。

## 要求仕様

### 動作環境・実装

- 対象OS: Windows 11（Windows 10でも動作すること）
- 実装言語: Python 3.10以上
- GUI: tkinter（標準ライブラリ）
- 外部パッケージに依存せず、標準ライブラリのみで実現する

### フィードの登録

- RSSフィードのURLは設定ファイル `feeds.txt` を手で編集して登録する（アプリ内に登録・削除のUIは設けない）
- `feeds.txt` は1行に1つのURLを記述する
  - 空行は無視する
  - `#` で始まる行はコメントとして無視する
- URL行の直後に、行頭を空白（スペースまたはタブ）でインデントした行を書くと、そのフィードに対する表示条件になる（フィードごとの表示パターン。詳細は「フィードごとの表示パターン」を参照）
- 配布物にはサンプル `feeds.example.txt` を含める。`feeds.txt` は利用者ごとのファイルのため配布物（Gitリポジトリ）には含めない
- `feeds.txt` が存在しない、または有効なURLが1件もない場合は、その旨を画面上に表示する。存在しない場合は `feeds.example.txt` をコピーして作成するよう案内する
- 対応フォーマット: RSS 2.0 / RSS 1.0 (RDF) / Atom
- 文字コードは UTF-8 のほか、Shift_JIS・EUC-JP などXML宣言で指定されたものに対応する

### フィードの取得

- 起動時に登録済みの全フィードを取得する
- 画面上の「更新」ボタンで全フィードを再取得する
- 取得中もGUIが固まらないこと（取得処理はバックグラウンドで行う）
- 一部のフィードの取得・解析に失敗しても、他のフィードの記事は表示する。失敗したフィードはステータスバー等で通知する

### 記事一覧の表示

- 全フィードの記事を1つの一覧に統合し、公開日時の新しい順に表示する
- 一覧の列: 日時（`YYYY-MM-DD HH:MM`、ローカル時刻）｜フィード名｜タイトル
  - フィード名はフィード自身のタイトル（RSSの `channel/title` 等）を用いる
  - 公開日時が取得できない記事は一覧の末尾に表示し、日時欄は空欄とする
- 未読記事は通常色、既読記事はグレーで表示する
- 画面の文字サイズは16ポイントとする（入力欄・ボタン・一覧・メニュー・ステータスバーすべて）

### フィードごとの表示パターン

- `feeds.txt` でフィードごとに表示パターンを指定すると、そのフィードの記事のうちパターンに一致するものだけを一覧に表示する
- 書式: URL行の直後のインデント行に `title:<パターン>` と書く
  - `title:` は記事タイトル（RSSの `<title>` 等）を照合対象とすることを表す
  - `title:` の後の文字列の前後の空白は無視する
- 照合は部分一致とし、大文字・小文字は区別しない
- 1つのフィードに複数のパターンを指定でき、いずれか1つに一致すれば表示する（OR条件）
- 除外パターン: インデント行に `!title:<キーワード>` と書くと、そのフィードの記事のうちタイトルにキーワードを含むものを一覧から除外する
  - 照合方法（部分一致・大文字小文字を区別しない・前後の空白を無視）は `title:` と同じ
  - 複数指定でき、いずれか1つに一致すれば除外する
  - `title:` と併用した場合は、`title:` のいずれかに一致し、かつ `!title:` のいずれにも一致しない記事を表示する（除外が優先）
- パターンを指定していないフィードは、従来どおり全記事を表示する
- あるフィードのパターンは、他のフィードの記事の表示に影響しない
- 次の行は無視する（エラーにはしない）
  - 直前にURL行がないインデント行
  - `title:` / `!title:` 以外で始まるインデント行、および `title:` / `!title:` の後が空のインデント行
  - インデントされた `#` で始まる行（コメント）
- `http://` / `https://` で始まる行は、インデントされていてもURL行として扱う
- パターンに一致しない記事は、画面上の絞り込み・「未読のみ表示」・「すべて既読にする」の対象にもならない（最初から存在しないものとして扱う）

### 絞り込み

- 画面上部の入力欄に文字列を入力すると、記事タイトルにその文字列を含む記事のみを表示する
- 入力に応じてリアルタイムに絞り込む（確定操作は不要）
- 大文字・小文字は区別しない
- 入力欄が空のときは全記事を表示する
- 「未読のみ表示」チェックボックスをONにすると、既読記事を非表示にする（文字列の絞り込みと併用可能）

### キー操作

- 記事一覧にフォーカスがあるとき、スペースキーで1ページ先へ、BackSpaceキーで1ページ前へスクロールする。スクロール後は表示先頭の記事を選択状態にする
- 絞り込み欄にフォーカスがあるときは、スペース・BackSpaceは通常の文字入力・削除として動作する
- 起動時は記事一覧にフォーカスを置く。絞り込み欄でEscキーを押すと記事一覧にフォーカスが移る

### 記事を開く・既読管理

- 一覧の記事をシングルクリックすると、既定のブラウザで記事URLを開く
- 記事URLが `http://` / `https://` 以外（`file:`、`javascript:` など）の記事は一覧に表示しない（悪意あるフィードによるローカルファイルやプログラムの起動を防ぐため）
- 開いた記事は既読となり、即座にグレー表示に変わる
- 既読情報は記事URLをキーとしてファイル（`read.json`）に保存し、アプリを再起動しても保持する
- 記事の右クリックメニューから「未読に戻す」を実行すると、その記事を未読に戻す
- 「すべて既読にする」ボタンで、現在表示中（絞り込み後）の記事をまとめて既読にする。このときブラウザは開かない

### 配布

- MIT License で公開する（`LICENSE`）

### ファイル配置

- `feeds.txt` と `read.json` はデータフォルダに置く
  - データフォルダは既定で起動時のカレントフォルダ。起動オプション `--data-dir <フォルダ>` で変更できる
  - 同梱のランチャー `RSSReader.pyw` をダブルクリックで起動した場合は、ランチャーと同じフォルダがデータフォルダになる

### 起動オプション

- `--data-dir <フォルダ>`: データフォルダを指定する
- `--help`: 使いかたを表示して終了する
- `--version`: バージョンを表示して終了する
- 不正なオプションを指定した場合は、エラーメッセージを表示して終了コード2で終了する

## 使いかた

1. 同梱の `feeds.example.txt` をデータフォルダ（既定ではアプリを起動するフォルダ）に `feeds.txt` という名前でコピーし、購読したいフィードのURLを1行ずつ記述する。

   ```powershell
   Copy-Item feeds.example.txt feeds.txt
   ```

   `feeds.txt` の記述例:

   ```text
   # ニュース
   https://news.example.com/rss.xml
   # ブログ
   https://blog.example.org/atom.xml
   # 特定の連載だけを表示する（タイトルに「週末レシピ」または「旅コラム」を含む記事のみ）
   https://magazine.example.net/feed/
       title:週末レシピ
       title:旅コラム
   # PR記事を除外する（タイトルに「PR」または「広告」を含む記事を表示しない）
   https://tech.example.jp/rss
       !title:PR
       !title:広告
   ```

   URLの次の行をインデントして `title:<パターン>` を書くと、そのフィードではタイトルにパターンを含む記事だけが表示される。複数行書いた場合は、いずれかを含む記事が表示される。`!title:<キーワード>` を書くと、タイトルにキーワードを含む記事が表示されなくなる。

2. アプリを起動する。

   ```powershell
   python -m rss_reader
   # データフォルダを指定する場合
   python -m rss_reader --data-dir C:\Users\me\rss
   ```

   エクスプローラーから起動する場合は `RSSReader.pyw` をダブルクリックする（コンソール画面は出ない）。

3. 起動すると全フィードの記事が新しい順に一覧表示される。

   ```text
   [絞り込み: ____________]  [□ 未読のみ表示]  [更新]  [すべて既読にする]
   日時              フィード     タイトル
   2026-11-08 21:30  サンプルニュース  新型CPUを発表...
   2026-11-08 20:12  サンプルブログ    クラウド移行の手引き...
   2026-11-08 18:05  サンプルニュース  （既読のためグレー表示）
   ---------------------------------------------------------------
   ステータス: 2件のフィードを取得しました（失敗 0件）
   ```

4. 絞り込み欄に文字列（例: `CPU`）を入力すると、タイトルに「CPU」を含む記事だけが表示される。
5. 記事をクリックすると既定のブラウザで記事が開き、その行がグレーになる。
6. 誤って既読にした記事は右クリック →「未読に戻す」で元に戻せる。
7. 新着を確認したいときは「更新」ボタンを押す。
