# RSS Reader

Windows 用のシンプルな RSS リーダーです。`feeds.txt` に登録したフィードの記事を新しい順に1つの一覧で表示し、クリックすると既定のブラウザで記事を開きます。開いた記事は既読としてグレー表示になり、アプリを閉じても記憶されます。

## 必要環境

- Windows 10 / 11
- Python 3.10 以上（[python.org](https://www.python.org/downloads/) のインストーラー版。tkinter が同梱されています）
- 追加のパッケージは不要です

## インストール

インストールは不要です。このフォルダをそのまま任意の場所に置いて使えます。

`rss-reader` コマンドとして使いたい場合は、pip でインストールすることもできます。

```powershell
pip install .
rss-reader            # コンソールを出さずに起動（データフォルダはカレントフォルダ）
```

## 使いかた

### 1. フィードを登録する

同梱のサンプル `feeds.example.txt` を `feeds.txt` という名前でコピーし、購読したいフィードの URL を1行に1つずつ書きます。

```powershell
Copy-Item feeds.example.txt feeds.txt
```

`#` で始まる行はコメント、空行は無視されます。

```text
# ニュース
https://news.example.com/rss.xml
# ブログ
https://blog.example.org/atom.xml
```

上の URL は架空の例です。実際に購読したいフィードの URL に書き換えてください。

#### フィードごとに表示する記事を絞る

URL の次の行をインデント（スペースまたはタブ）して `title:文字列` と書くと、そのフィードではタイトルにその文字列を含む記事だけが表示されます。他のフィードの表示には影響しません。

```text
https://magazine.example.net/feed/
    title:週末レシピ
    title:旅コラム
```

逆に `!title:文字列` と書くと、そのフィードではタイトルにその文字列を含む記事が表示されなくなります。

```text
https://tech.example.jp/rss
    !title:PR
    !title:広告
```

- 大文字・小文字は区別しない部分一致です
- 複数行書くと、`title:` はいずれかを含む記事が表示され、`!title:` はいずれかを含む記事が除外されます
- 同じフィードに `title:` と `!title:` を併用すると、`title:` に一致し、かつ `!title:` に一致しない記事だけが表示されます
- 条件に一致しない（除外された）記事は、画面上の絞り込みや「すべて既読にする」の対象にもなりません
- `title:` / `!title:` 以外で始まるインデント行は無視されます

RSS 2.0 / RSS 1.0 (RDF) / Atom に対応しています。文字コードは UTF-8 のほか Shift_JIS・EUC-JP なども扱えます。

### 2. 起動する

エクスプローラーで `RSSReader.pyw` をダブルクリックします（コンソール画面は出ません）。この場合、`RSSReader.pyw` と同じフォルダの `feeds.txt` が使われます。

#### タスクバーにピン留めする

`RSSReader.pyw` で起動したウィンドウのタスクバーアイコンを右クリックし、「タスクバーにピン留めする」を選びます。以降はピン留めしたアイコンからアプリを起動できます。

以前のバージョンでピン留めしたアイコン（クリックすると IDLE が起動するもの）がある場合は、いったんピン留めを外してから改めてピン留めしてください。`RSSReader.pyw` を別のフォルダへ移動した場合も、ピン留めし直す必要があります。

コマンドラインから起動する場合は、プロジェクトのフォルダで次のように実行します。

```powershell
$env:PYTHONPATH = "src"
python -m rss_reader                          # カレントフォルダの feeds.txt を使う
python -m rss_reader --data-dir C:\Users\me\rss   # 別のフォルダの feeds.txt を使う
```

| オプション | 説明 |
|---|---|
| `--data-dir DIR` | `feeds.txt` と `read.json` を置くフォルダ（既定: カレントフォルダ） |
| `--version` | バージョンを表示して終了 |
| `-h`, `--help` | 使いかたを表示して終了 |

### 3. 画面の操作

```text
[絞り込み: ____________]  [■ 未読のみ表示]            [更新]  [すべて既読にする]
日時              フィード              タイトル
2026-11-09 00:09  サンプルブログ        クラウド移行の手引き…
2026-11-08 13:32  サンプルニュース      新型CPUを発表…
2026-11-08 10:00  サンプルニュース      （既読の記事はグレーで表示）
--------------------------------------------------------------------------------
2件のフィードを取得しました（失敗 0件）
```

| 操作 | 動作 |
|---|---|
| 記事をクリック（または選択して Enter） | 既定のブラウザで記事を開き、既読（グレー）にする |
| 記事を右クリック →「未読に戻す」 | 既読を取り消す |
| スペース／BackSpace（一覧にフォーカスがあるとき） | 1ページ先へ／前へスクロール |
| 絞り込み欄で Esc | 一覧にフォーカスを移す（スペースでのページ送りに戻る） |
| 絞り込み欄に入力 | タイトルに入力文字列を含む記事だけを表示（大文字・小文字は区別しない） |
| 「未読のみ表示」をオン | 既読の記事を隠す（起動時はオン） |
| 「更新」 | 全フィードを再取得する（起動時にも自動で取得） |
| 「すべて既読にする」 | 表示中の記事をまとめて既読にする（ブラウザは開かない） |

記事のリンクが `http://` / `https://` 以外（`file:` など）の記事は、安全のため一覧に表示しません。

取得に失敗したフィードがあると、画面下のステータスバーに失敗件数と URL が表示されます。他のフィードの記事は通常どおり表示されます。

### データファイル

| ファイル | 内容 |
|---|---|
| `feeds.example.txt` | `feeds.txt` のサンプル（配布物に同梱） |
| `feeds.txt` | 購読するフィードの URL 一覧（`feeds.example.txt` をコピーして作り、手で編集する） |
| `read.json` | 既読にした記事の URL（自動で作成・更新される） |

`feeds.txt` と `read.json` は使う人ごとのファイルなので Git の管理対象外です（`.gitignore` で除外）。

`read.json` を削除すると、すべての記事が未読に戻ります。内容が壊れていた場合は `read.json.bak` に退避され、未読の状態から始まります。

## 開発者向け

### テストの実行

標準ライブラリの `unittest` を使います。ネットワークには接続しません。

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
```

### ディレクトリ構成

```
RSSReader.pyw       ダブルクリック用ランチャー

tests/              単体テストとフィクスチャ
doc/                要求仕様・設計・実装計画
```
